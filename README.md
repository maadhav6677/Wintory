# Wintory

Wintory is a production-grade AI-powered inventory management SaaS.

## Repository Layout

This repository is structured as a monorepo containing all components of the Wintory SaaS platform:

- **[backend/](./backend)**: Express + TypeScript + Prisma API backend server.
- **[frontend/](./frontend)**: Next.js user interface (placeholder).
- **[docs/](./docs)**: Shared architecture, API, and product design documentation.

## Running the Application

To run the entire stack locally using Docker Compose:

```bash
docker compose up --build
```
